En: SpaceSandBox is a sandbox mod that lets you create any planetary system you desire. The mod is heavily inspired by Universe Sandbox. Standard Minecraft mechanics have been completely removed to ensure a stable and smooth gameplay experience.

A custom physics engine lets you experiment with space objects however you like. You can put the Earth into orbit around a black hole or launch 100 suns into it. The mod has three main tools for this: 1) static object creation, which creates an object without accelerating it; 2) orbit mode, used to place objects into orbit. There's a slider for automatic velocity calculation to help you achieve a stable orbit, or you can disable it and experiment with fine-tuning the orbit; and 3) launch mode, which lets you launch one object into another. Just click anywhere and enjoy. For complete control, time management is included, including stopping, accelerating, and decelerating. Double-clicking an object will lock the camera on it, allowing you to examine it in detail. This mode offers two tools: a flashlight, which doesn't illuminate the object but merely removes shadows; and a ray remover, useful for stargazing. This mode also includes a menu for adjusting planetary parameters.

Ru: SpaceSandBox — это мод-песочница, позволяющая создавать любые планетные системы по вашему желанию. Мод во многом вдохновлён Universe Sandbox. Стандартные механики Minecraft были полностью удалены для обеспечения стабильного и плавного игрового процесса.

Собственный физический движок позволяет экспериментировать с космическими объектами так, как вам угодно. Вы можете вывести Землю на орбиту вокруг чёрной дыры или запустить в неё 100 солнц. Мод имеет три основных инструмента для этого: 1) создание статических объектов, которое создаёт объект без его ускорения; 2) режим орбиты, используемый для размещения объектов на орбите. Есть ползунок для автоматического расчёта скорости, который поможет вам добиться стабильной орбиты, или вы можете отключить его и поэкспериментировать с тонкой настройкой орбиты; и 3) режим запуска, который позволяет запускать один объект в другой. Просто щёлкните в любом месте и наслаждайтесь. Для полного контроля предусмотрено управление временем, включая остановку, ускорение и замедление. Двойной щелчок по объекту заблокирует камеру на нём, позволяя вам детально изучить его. В этом режиме доступны два инструмента: фонарик, который не освещает объект, а лишь удаляет тени; и инструмент для удаления лучей, полезный для наблюдения за звёздами. Этот режим также включает меню для настройки параметров планет.

**Внимание: Мод содержит реалистичные симуляции открытого космоса, экстремальные космические масштабы, полную темноту и изображения колоссальных астрономических объектов. Игрокам с астрофобией, мегалофобией, талассофобией или повышенной тревожностью строго не рекомендуется устанавливать данный мод, так как геймплей может спровоцировать приступы страха и панические атаки.**
